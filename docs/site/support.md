# Support

Use GitHub issue forms for reproducible bugs, scientific validation questions,
documentation problems, and feature requests. Use GitHub Discussions for
open-ended research and usage conversation.

Before reporting:

1. Search existing issues.
2. Run `emrf doctor --report`.
3. Run the narrow command that reproduces the problem.
4. State OS, Python version, EMRF version, evidence class, and whether the
   input is synthetic or observational.
5. Remove secrets and restricted data.

Security vulnerabilities must follow the private process in `SECURITY.md`;
do not file a public exploit report.
