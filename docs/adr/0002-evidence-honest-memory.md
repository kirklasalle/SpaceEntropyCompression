# ADR 0002: Evidence-honest scientific memory

- Status: accepted
- Date: 2026-10-11

## Decision

The EMRF knowledge graph is a versioned, schema-validated scientific record.
Claims have lifecycles and typed evidence. Software, synthetic, published, and
observational evidence remain distinct. Non-proposed claims require evidence.

## Consequences

Historical claims are preserved with qualifications instead of silently
deleted. Passing tests cannot automatically promote a physics claim.
