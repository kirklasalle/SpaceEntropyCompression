# Recovered Antigravity development evidence

**This is a historical archive, not a collection of validated scientific results.**
Some preserved documents contain demonstrably unsupported "proved", "resolved",
"100/100" and "confirmed" claims. Read the [recovery audit](../../ANTIGRAVITY_RECOVERY_AUDIT.md)
and [curated knowledgebase note](../../../knowledgebase/antigravity_recovered_theory.md)
before using them.

## What is preserved

- Exact bytes of selected September/October EMRF drafts, early code snapshots,
  execution logs and eight visualizer artifacts.
- Exact duplicates already present in the repository are referenced rather than
  copied again, including both audio attachments.
- Project-only extracts from mixed-project August inventories.
- Five recovered user-text snippets and visible test-execution events, separated
  from opaque IDE/model fields.
- A pre-recovery knowledge-graph snapshot, retained to explain later corrections.

The [manifest](manifest.json) records source paths relative to the authorized
brain archive, source/output hashes, byte counts, dates, disposition and evidence
limits. Raw scripts and TeX snapshots are stored with an added `.txt` suffix;
they were not executed or imported. Sources are immutable historical copies.
Existing file links inside them may be obsolete or point outside this archive.

   unsupported conclusions that the recovery audit explicitly does not endorse.
5. [Execution events](extracts/execution_events.json) and source logs:
   evidence of commands/tests running, not proof that their inputs were real.

## Privacy and scope

No raw message JSON, model signatures, private keys, unrelated project records,
or external uploads are part of this archive. The full private file inventory
remains in the Copilot session workspace, not the repository. A local allowlist
and credential-pattern check controlled copying; this is not a general secret
scanner certification.

The brain folder contains artifacts and partial user-message payloads, not a
demonstrably complete conversational history. No claim is made that every
spoken idea or every image in unrelated sessions has been recovered. The full
audio was not retranscribed; exact existing copies and their existing transcripts
are identified in the manifest.
