## 2. Most important recovered concepts

### A. Thermodynamics downstream; geometric information separately upstream

The September working manuscript explicitly says that entropy does not produce
matter and that thermodynamics is downstream of matter and interactions. It
separately asks whether an entropy/information measure helps define a deeper
geometric state. It lists thermodynamic, statistical, entanglement, von Neumann
and black-hole entropy as quantities that must not be interchanged.

**Why this matters:** the prior audit was right that the collision code does not
generate thermodynamics. But it would be too strong to conclude that *any*
entropy input contradicts your intention. Different entropy meanings, or a
properly specified feedback model, could coexist. The archive supports that
conceptual distinction; it does not supply its missing coupled equations.

[Source: September paragraphs 019-020, 033-034 and 088](archive/antigravity_recovery/sources/e5da707a-459a-4d74-91d8-b0c8df2a569a/emrf_full_text.txt).

existing project dialogue—not a newly recovered full original user transcript.

### B. Compression is not restricted to one interpolation law

The record preserves C_G, C_E, C_S and C_GSE as alternatives: geometry,
appropriate gravitational-energy measures, entropy/information coupling and
combinations. C is also described dynamically as F(E,S,geometry,t), not merely
a static curvature slice.

The matter mapping M = k(C/C0)^alpha is explicitly called an ansatz.
No failure of the particular square-root galaxy law can be generalized to every
possible member of these families. Conversely, a family name does not define a
prediction.

[Source: September document-generator snapshot](archive/antigravity_recovery/sources/e5da707a-459a-4d74-91d8-b0c8df2a569a/update_emrf_docx.py.txt).

## 4. Checks on historical results

### Quantum mass normalization was present from the original scratch code

The [earlier quantum source](archive/antigravity_recovery/sources/8de1a404-0739-40f4-a4af-8d636b604cc9/quantum_vibrational_compression.py.txt)
already divides its integrated mass by its ratio to the input mass. It is not a
later corruption introduced by the current audits.

For the specified envelope, change variable to x=r/lambda. Before the final
renormalization,

$$\frac{m_{\rm raw}}{m_{\rm input}}
=2\pi\int_0^\infty\frac{x^2e^{-2x}}{(1+x)^2}\,dx
\simeq0.343599334.$$

The last code step then gives m_raw/(m_raw/m_input)=m_input. Recovering identical
particle masses therefore is not an independent prediction. This integral was
checked numerically without executing the archived script.

### The black-hole code is an exact duplicate, not a missing alternate proof

The recovered black-hole source is byte-identical to the already present
implementation, which assigns k_B/(4 l_P^2). The older first-use-case prose says
"two polarization states times two boundary projections" explains four, but no
defined counting calculation connects that statement to the entropy density.
That narrative is already in the project; it is not a newly recovered solution.

The historical first-use-case table also contains a directly checkable error:
for 10^-18 solar masses, r_s=2GM/c^2 is approximately **2.95e-15 m**, not the
listed **2.95e-45 m**. This 30-order discrepancy invalidates that table entry,
not the standard Schwarzschild formula.

### Historical CI logs demonstrate execution, not physical confirmation

[Task 1598](archive/antigravity_recovery/sources/8de1a404-0739-40f4-a4af-8d636b604cc9/task-1598.log.txt)
records 145 passing tests alongside expected slope -6.00, measured slope -0.80,
and "Match: approximate". The same mismatch appears in several successful runs.
Thus the preserved logs explain how an all-green software pipeline could coexist
with an invalid physical claim.

[Task 153](archive/antigravity_recovery/sources/67e60b60-238b-4fb1-8fcc-1e4c3034f1fe/task-153.log.txt)
records 177 tests passing and one failure caused by a manuscript section-title
change. Subsequent logs show 178 passing tests. This is real execution history,
but the failed assertion was about document structure, not a physical proof.

The recovered screenshots and WebP show the illustrative dashboard operating.
They are not telescope observations, measured mass maps or a dynamical movie
of colliding gravitational wells.
